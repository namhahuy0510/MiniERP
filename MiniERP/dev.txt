# EF Core Migration Commands

# Tạo migration mới
dotnet ef migrations add AddStartEndDateToEmployee

# Áp dụng migration vào database
dotnet ef database update

# Xóa migration cuối cùng (nếu chưa update DB)
dotnet ef migrations remove

# Rollback database về migration trước đó
dotnet ef database update PreviousMigrationName

# Xóa toàn bộ migrations (xóa thư mục Migrations/ thủ công)
dotnet ef migrations add InitMigration
dotnet ef database update

# Xem các package đã cài
dotnet list package
